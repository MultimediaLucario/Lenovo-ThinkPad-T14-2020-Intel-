## Introduction

### EFI folders

This repo includes multiple EFI configuations for different macOS Versions.

| EFI               | Description                                                               | Type      |
| ----------------- | ------------------------------------------------------------------------- | --------- |
| `EFI - Ventura`     | Supports macOS Ventura (using Airportitlwm)		                | `Stable`  |
| `EFI - Sequoia`   | Supports macOS Sequoia (using Airportitlwm)				| `Stable`  |         

> **Note** The Sequoia configuration is still a work in progress as the video output is still not working. Use ```EFI - Ventura``` instead for a better experience.
